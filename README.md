# Selenium WebDriver — Stepik

Практические задания по Selenium WebDriver, выполненные в рамках курса на Stepik.

## Задания

* `test1.py` — поиск элементов на странице
* `test2.py` — поиск ссылки по тексту
* `test3.py` — использование `find_elements`
* `test4.py` — уникальность селекторов
* `test5.py` — работа с checkbox и radiobutton
* `test6.py` — получение значения атрибута через `get_attribute`
* `test7.py` — работа с выпадающим списком
* `test8.py` — прокрутка страницы с помощью `execute_script`
* `test9.py` — загрузка файла
* `test10.py` — работа с alert
* `test11.py` — переход на новую вкладку
* `test12.py` — явные ожидания

Все задания написаны на Python с использованием Selenium WebDriver.
